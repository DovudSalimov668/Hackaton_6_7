# Инструкции по использованию Кейса 4: Анализ расходов

## ⚙️ Подготовка данных

### 1. Создайте директорию для CSV файлов:
```
mkdir mock_data
```

### 2. Поместите в `mock_data/` файлы:
- `transactions.csv` - файл с транзакциями
- `transaction_categories.csv` - справочник категорий

### 3. Формат файлов:

**transactions.csv:**
```
transaction_id,transaction_date,amount,currency_code,description,category_id,is_cancelled
1,15/11/2024 13:04:30,17551,RUB,Покупка продуктов в Перекрёстке,1,f
```

**transaction_categories.csv:**
```
category_id,category_name,description,is_expense,parent_category_id
1,Продукты питания,Покупка продуктов в магазинах,t,
2,Кафе и рестораны,Питание вне дома,t,
```

## 🚀 Запуск анализа

```bash
python expense_analyzer.py
```

## 📊 Что делает программа:

### 1. Загрузка данных ✅
- Читает CSV файлы
- Парсит транзакции (дата, сумма, категория)
- Загружает справочник категорий

### 2. Классификация расходов ✅
- Группирует транзакции по категориям
- Фильтрует только расходы (is_expense=true)
- Исключает отменённые операции

### 3. Подсчёт долей ✅
- Общая сумма расходов
- Сумма по каждой категории
- Доля каждой категории (%)
- Количество операций
- Средний чек

### 4. Визуализация ✅

**Текстовая:**
```
==================================================
ОТЧЁТ ПО РАСХОДАМ КЛИЕНТА
==================================================

💰 ОБЩАЯ СУММА РАСХОДОВ: 1,234,567.89 руб.
📊 КОЛИЧЕСТВО КАТЕГОРИЙ: 15
📝 КОЛИЧЕСТВО ОПЕРАЦИЙ: 250

--------------------------------------------------
№    КАТЕГОРИЯ                   СУММА (руб.)    ДОЛЯ %  
--------------------------------------------------
1    Продукты питания            345,678.90      28.0%
2    Транспорт                   198,765.43      16.1%
...
```

**Графическая:**
- 🥧 Круговая диаграмма (Pie Chart) - доли по категориям
- 📊 Столбчатая диаграмма (Bar Chart) - суммы по категориям

## 💡 Результаты для банка

Программа предоставляет:
- Аналитику клиентских трат
- Топ-категории расходов
- Данные для персонализации предложений (кешбэк, спецкарты, рекомендации)
